# Punycode Blocker

[English](README.md) | 日本語

国際化ドメイン名 (Punycode、`xn--` で始まるラベル) を含むドメインへの通信をすべてブロックする Chrome 拡張機能 (Manifest V3) です。

## 目的

国際化ドメイン名には、ASCII の英字とほとんど見分けがつかない文字を使えます。これを悪用して有名なサイトに見せかけたドメインがフィッシングに使われることがあります (IDN ホモグラフ攻撃)。この拡張機能は、正規のものも含めて国際化ドメイン名をすべてブロックするという単純な方法をとっています。

## 仕組み

Chrome は URL を処理する際、ASCII 以外の文字を含むドメイン名を Punycode 形式に変換します。変換されたラベルは `xn--` で始まります。この拡張機能は `declarativeNetRequest` API を使っており、ホスト名に `xn--` で始まるラベルを含む通信を Chrome がブロックします。

ルールは [`rules.json`](rules.json) に定義しています。

```
^[a-z][a-z0-9+.-]*://([^/?#@]*@)?([^/?#:@]*\.)?xn--
```

| URL | 結果 |
| --- | --- |
| `https://xn--abc.example/` | ブロック |
| `https://www.xn--abc.example/page` | ブロック (サブドメイン) |
| `https://shop.example.xn--abc:8443/` | ブロック (トップレベルドメイン、ポート指定あり) |
| `wss://user@xn--abc.example/socket` | ブロック (http(s) 以外のスキーム、ユーザー情報あり) |
| `https://example.com/xn--abc` | ブロックしない (パスに含まれる `xn--`) |
| `https://example.com/?q=xn--abc` | ブロックしない (クエリに含まれる `xn--`) |
| `https://axn--b.com/` | ブロックしない (ラベルが `xn--` で始まっていない) |

ページの読み込み、フレーム、スクリプト、スタイルシート、画像、フォント、XHR/fetch、WebSocket、メディアなどのリソースが対象です。

## 制限事項

- 正規の国際化ドメイン名のサイトもブロックします。許可リストはありません。
- ASCII 文字だけで作った紛らわしいドメイン (例: `m` の代わりに `rn`) はブロックしません。
- ルールが適用されるのは、Chrome のネットワーク処理に届いたリクエストのみです。Chrome のドキュメントによると、Service Worker が返したレスポンスや `CacheStorage` から取り出したデータには作用しません。
- Chrome 以外のアプリケーションの通信には影響しません。
- Chrome のみを想定しています。ほかのブラウザでの動作は確認していません。

## インストール

1. このリポジトリをクローンするか、ダウンロードします。
2. Chrome で `chrome://extensions` を開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このリポジトリのフォルダを選択します。

### シークレットモード

シークレットモードのウィンドウでも使う場合は、`chrome://extensions` でこの拡張機能の [詳細] を開き、「シークレット モードでの実行を許可する」をオンにしてください。この設定がオフの間は、シークレットモードのウィンドウでは動作しません。

国際化ドメイン名のサイトを一時的に閲覧したい場合は、`chrome://extensions` でこの拡張機能をオフにしてください。

## 権限

この拡張機能が要求する権限は `declarativeNetRequest` のみです。JavaScript は含まれておらず、`rules.json` のルールは Chrome 自身が適用します。ページの内容や閲覧履歴を読み取ることはありません。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `manifest.json` | 拡張機能のマニフェスト |
| `rules.json` | `declarativeNetRequest` のブロックルール |
